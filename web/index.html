Hybrid Signature Checker

Paste a QoreChain testnet transaction hash. The page reads the transaction back from the chain and shows both signatures — classical secp256k1 and post-quantum ML-DSA-87 — plus the chain's own verification verdict.

Read-only: no wallet, no keys, nothing is signed or sent.

Full record: open in the explorer (switch the explorer to Testnet if the hash is not found).

Built for Build Before Q-Day (Quantum Pass) on the QoreChain Diana testnet. Transactions are produced by the companion CLI (pnpm send); this page only reads public chain data.
